# Score Transposer

本專案是本機優先的樂譜轉調工具：在瀏覽器中轉換旋律與和弦，並以本機 OMR 辨識 PDF 樂譜。

## 分階段路線

### Phase 1 — 可驗證 MVP（目前）

- 單旋律聲部的 PDF/JPG/PNG 匯入
- 多頁 PDF 的本機 OMR 辨識
- 原調／目標調轉換
- 和弦、斜線和弦、歌詞、延音與反覆結構保留
- 八分音符橫杠分組與調號記號處理
- 瀏覽器預覽、PDF 與 MusicXML 匯出
- 逐小節人工核對與修正

### Phase 2 — 多頁與辨識品質

- 逐頁預覽與頁碼定位
- MusicXML beam、voice、ending 的完整保存
- OMR 置信度與待核對標記
- 多聲部與較複雜節奏的明確錯誤提示

### Phase 3 — 簡譜模式

- 數字、升降記號、八度點與節奏記號辨識
- 簡譜與和弦同步轉調
- 五線譜／簡譜輸出選項

### Phase 4 — 可分享版本

- 跨平台本機啟動包
- 使用者自行部署的辨識服務
- 匯入／匯出與版本化的校正版樂譜資料

## 原則

移調、排版與 PDF 輸出不呼叫 ChatGPT 或大型語言模型 API；自動辨識在使用者自己的電腦執行。自動辨識結果必須先核對，才建議用於演出。
